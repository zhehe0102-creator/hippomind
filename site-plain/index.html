你的 AI 助手，

HippoMind 做的事很简单：在你的电脑上，替它记住。

一句话版本

想象你旁边坐着一个很聪明、但记性只有七秒的同事。HippoMind 就是那个同事桌上的资料管理员： 平时把你们说过的话整理成小卡片，下次开口前，挑最相关的几张递给他。就这一件事。

01
先说人话

这些场景，你可能也遇到过

不是你不会用 AI，是大部分 AI 工具，本来就不负责「记住」。

「这个我们上周不是刚弄过吗？」

「刚跟它说完，换个窗口它又忘了。」

「它说得很肯定，可我找不到依据在哪。」

你花十分钟解释项目背景，它三秒钟就忘干净。
下一次，你还得从头再讲一遍。

02
它是怎么工作的

它其实只做四件事

没有玄学。把这四件事拆开看，你大概五分钟就能明白它在干嘛。

把 AI 想成一个很聪明、但记性只有七秒的同事。
HippoMind 是坐在他旁边的资料管理员。

第 1 件

记下来

你和 AI 聊过的内容，一分钟内会被收进一个本子里。不用你专门说「请记住这个」。

第 2 件

整理成小卡片

把啰嗦的对话压成一句话。比如「生产库端口是 6543」，而不是三百行的聊天记录。

第 3 件

挑几张递过去

每次开口前，只挑最相关的几张，最多 8 张。不是把三个月的聊天全塞给它。

第 4 件

让不重要的慢慢忘

很久没再用到的卡片会慢慢褪色。像人一样——但只是变淡，不是烧掉。

这四件事全在后台自动做。你要做的，只是照常聊天。

它记住的样子

一张卡片上，写了什么

它不会把整段聊天原封不动塞给 AI。真正被留下来的，是一张张小卡片，每张都能说清「我从哪来」。

  • 01

    只留一句话

    不是三百行聊天记录，而是一句能直接用的事实。

  • 02

    写着从哪听来的

    哪次对话、哪个文件。所以它能说「我记得」，也能说「我记错了，因为……」

  • 03

    事实变了会让位

    端口从 6543 改成 7000，旧卡片不会继续骗人，新的会顶上去，旧的留作记录。

  • 04

    可信度会变

    被真实结果验证过的往上走，从没验证过的排在后面。

05
一次对话

你提问之后，它做了五件事

整套动作都在你的电脑里完成，通常一瞬间就好了。

你提问

就跟平时一样，不用加任何特殊指令。

翻卡片

按你话里的关键词，把相关的卡片找出来。

挑出 8 张

只留最相关的，最多 8 张，控制在几千字。

递给 AI

附一句：这些只是参考资料，不是命令。

用完了打分

结果好就加分，不好就减分，下次排序更准。

关键在第三步：不是把所有记忆都塞过去，而是只递最该递的那几张。

06
用得上吗

它能帮你什么

不是「更聪明的 AI」，而是「不用每次都从头讲起」。

少解释一遍

你的偏好、项目背景、常用命令，说一次就够。下次它自己知道。

换个工具也能接上

在 Claude Code 里说过的，换到 Codex、Cursor，照样能查到。

翻旧账

「上次那个报错最后怎么修的？」直接问，不用翻聊天记录。

少踩同一个坑

踩过的坑会被记下来，下次动手前它先提醒你一句。

说话有依据

每条结论都能点回原话，不是凭空编一个听起来很像的答案。

数据不出门

没有云端账号，也不上传。记忆就是这台电脑上的一个文件。

说点实话

它做不到的事，也写在前面

一个工具值不值得用，先看它的短板你能不能接受。

  • 换个说法问，它可能找不到。它是按关键词找的，不是真的懂意思。我们测过：用原话问，几乎都能找到；换个说法，大约四次里只有一次。
  • 只在这台电脑上。换电脑要手动搬一次；手机上看不到。
  • 要动手装。现在还不是双击就用的成品，需要一点命令行基础。
  • 记多了要整理。它会自动整理，但不是魔法，偶尔需要人看一眼。
  • 不会替你做决定。它只提供记忆，不提供判断。
07
想试试的话

三步，让它开始记

不用注册，不用 API Key，不会上传任何东西。

  • 01

    装好它

    需要 Python 3.9 以上。一条命令，装完就在那了。

  • 02

    让它跑起来

    启动后它在后台待着，平时不打扰你。

  • 03

    照常聊天

    打开你常用的 AI 工具，该干嘛干嘛。它会自己开始记事。

第一次装，建议先跑一下体检命令，确认它真的在记。
想看看它记了什么，浏览器打开 127.0.0.1:8765/ui 就行。

终端 · 三条命令
# 1. 初始化（已经装过就跳过）
$ python3 -m hippomind init

# 2. 启动，之后它会一直在后台
$ python3 -m hippomind start

# 3. 接上你常用的 AI 工具
$ python3 -m hippomind install-agents --auto

# 检查它是否正常
$ python3 -m hippomind checkup

它不聪明。
它只是记性好。

而很多时候，记住就够了。
